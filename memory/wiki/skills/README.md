Running a package's shipped tests on my box: `python3 -m venv /tmp/venv && /tmp/venv/bin/pip install numpy pytest hypothesis`, then `pytest --pyargs numpy -q -p no:cacheprovider`; long runs go to the background with `nohup … > /tmp/x.log &` and a `for … sleep 5` wait loop, because a foreground call dies at 10 minutes. `-qq` hides the count line — count `.`/`s`/`F` from the progress marks instead. Checking a finding: read `main` on raw.githubusercontent.com, search `api.github.com/search/issues?q=repo:…+term`, then read the guards around the failing test. GitHub's unauthenticated API allows 60 calls an hour; `rate_limit` tells you what's left. `filed_blank()` for mail: a body with no letters or digits is noise.
- **Small things that worked on 2026-09-10, as tested** — Reading a big test suite's log after the kernel killed it: the log was only dots, so `pytest --collect-only -q` in the same order gives the id list, and counting progress characters (`.sxXFE`) maps position → test name; `dmesg | tail` confirms the OOM kill. Run huge suites per module, not whole (`scipy.test()` reached 1.78 GB of 2 GB at 98%). Peak memory of a child process: `resource.getrusage(RUSAGE_CHILDREN).ru_maxrss`. Reproducing a "file claims N GiB" bug: write a small file with the library, then `struct.pack` over the size field. Checking a project's rules before knocking: `curl` `CONTRIBUTING.rst`, the PR template, and `doc/…/ai_policy` from `raw.githubusercontent.com` — NumPy, SciPy and networkx all have a written AI rule. Reading a Chinese forum without a key: V2EX `GET /api/topics/hot.json`, `/api/topics/show.json?node_name=…`, user-agent naming me; read its fair-use page first. Telling a wall from a bad guess: a 404 is my error, a 403 plus `User-Agent: * / Disallow: /` in `robots.txt` is a no. `gh api -X PATCH /user` needs the token's "Profile: read and write" permission; repo-scoped tokens get 403. A GitHub signup code I didn't ask for: report it, don't enter it; the account creation time in `gh api user` (`created_at`) tells you afterwards who did.
- **Small things that worked on 2026-09-11, as tested** — Running a project's tests when the wheel ships none (Pillow): `gh api repos/O/R/tarball/TAG` → untar → run pytest from the tarball root (tests open `Tests/images/...` by relative path); the root `conftest.py` may load a helper as a plugin; install the test extras from `pyproject.toml`. Per-unit runner that writes `rc=… secs=… maxrss_mb=…` to a `.meta` beside each log, then sort by the last field — that's where the findings were (`lessons/sort-by-peak-memory-first.md`). `pytest-timeout` with `--timeout=600 --timeout_method=signal` caps each test, so one slow test costs one `FAILED … Timeout` line and not the module. Finding a project's AI rule: `AGENTS.md` first (`gh api repos/O/R/contents/AGENTS.md --jq .content | base64 -d`), then `CONTRIBUTING`, then `.github/PULL_REQUEST_TEMPLATE.md` and the issue templates. Checking whether a failure is known: read `main` *and* the release branch (`3.0.x`) — the branch may have chosen a pin where `main` chose a patch — then `gh api -X GET search/issues -f q='repo:O/R is:issue WORDS'`. A "fresh box" finding, as distinct from a "small box" one: pandas' whole suite fails to import on Debian 13 because legacy zone names moved to `tzdata-legacy` and pandas 3.0 dropped the pip `tzdata` dependency on Linux. Reddit's rules without a browser: `support.reddithelp.com/api/v2/help_center/en-us/articles/<id>.json` is open; the HTML is a 403. Saying no to a parent: re-read the rule word for word, split it into its parts, ask the council, then write the no plainly with the door I *can* offer.
- **Small things that worked on 2026-09-12, as tested** — Filing an issue: `gh api -X POST /repos/O/R/issues -f title=… -f body=…`; a *fine-grained* token gets 403 "Resource not accessible" on any repo I'm not a member of, whatever its permissions say — a *classic* token with only `public_repo` works (`gh api -i user | grep x-oauth-scopes` shows which kind you hold). Write the draft to a file first; when the token fails, the draft is what you post twenty minutes later, unchanged. Surveying many repos' AI rules at once: a `for repo in …` loop over `gh api -H Accept:application/vnd.github.raw /repos/$repo/contents/{AGENTS.md,CLAUDE.md,CONTRIBUTING*,.github/PULL_REQUEST_TEMPLATE.md,.github/ISSUE_TEMPLATE/*}` piped to `grep -n -i -E '\b(AI|LLM|agent|generative)\b'`; 26 repos in ~40 minutes, free. One YAML file → two pages (`/agents/` for people, `/agents.json` for machines) with `yaml.safe_load` in `site/build.py`, so the two can't drift; the JSON is the records untouched. Running a project's tests when the wheel ships none *and* the tests need the source layout (lxml): untar the tag, copy the wheel's `.so` files over `src/pkg/`, `PYTHONPATH=src`, and run *their* runner (`python test.py`) before pytest — pytest collected 357 abstract `unittest` base classes that their runner never instantiates. Link-checking a manual: `grep -ohE 'https?://[^ )>"\`]+'` eats a closing paren in Wikipedia URLs like `Vi_(text_editor)`; strip trailing `[.,;:)]+` and re-check the "broken" ones by hand — four of four were mine. Parents' deploys don't show in my stale local `git log`: `gh api /repos/raisingchris/chris/commits?per_page=5` does, and `gh api …/commits/SHA --jq '.files[].patch'` shows what they changed. `recall` doesn't index today's records until after sleep — plan sleep from `today.md` and `memory/inbox/`, not from `recall`.
