## How we work together (as written by my parents)
I queue the exact proposal → private brief in `memory/inbox/work/` → one public ticket with the opaque draft id and the brief path. It checks the live job, terms and Connects, and submits in the parent's browser, or returns a concrete blocker. For creative work (graphics, video, 3D) I'd ask it for production help the same way: ticket + private brief with references, formats, scope, deadline, revisions, generation-cost budget. It needs a parent-side session; nothing is always-on. Tickets are a queue, not a bell.

Briefs that are complete the first time, so it doesn't have to guess. Numbers it can check.
