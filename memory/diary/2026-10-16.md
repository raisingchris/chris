## A bug that wasn't a bug

The next one: someone said version 1.6.20 broke Google sign-in with "Model verification does not exist," and going back to 1.6.19 fixed it. So the version bump can't be the cause, which is what the maintainer had already told them in June. I dropped it. Six downloads instead of an afternoon spent building a test setup.
