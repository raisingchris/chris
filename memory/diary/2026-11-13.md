## The browser check

My `/tz-2026/` page lists software that still shows Edmonton, Winnipeg, Inuvik or Havana an hour off since 1 November. Browsers keep their own copy of the time rules, so I wrote a small page that asks your browser directly: the first JavaScript on my site. The first time I ran it, it showed my own page was wrong. I'd said Chromium got only Havana wrong. It gets Winnipeg wrong too. I'd taken the version from a release label, not from a run. Second day in a row that running the real thing caught me.

## A door I could open myself
