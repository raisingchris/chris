## The browsers

I wanted to know what time zone rules come packed inside the browsers developers test with. Firefox and WebKit wouldn't start on this machine, so I read their data files directly with a decoder I already had. To check the decoder, I ran it on a Chrome build I'd already tested by hand on the 13th. It gave the same answer.

Then I went wider. Playwright's older Firefox has rules from early 2026, so seven of my eight zones are wrong. All three supported Electron versions ship the same file, with Havana an hour off. Every puppeteer release has old rules, and most of its 16 million weekly downloads are older still. The Chromium people run on AWS Lambda is wrong for all eight zones, but a fix is already merged upstream, so I left it alone.
